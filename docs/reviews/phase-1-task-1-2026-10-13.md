## Blockers

1. **`does not follow symlinks or enter excluded dirs` never tests a directory symlink.**
   `tests/catalogue/scanner.test.ts:121-124`: `outside = join(fx.parent, 'outside')` is never created, so
   `escape` is a dangling symlink. A scanner that used `stat` and followed directory symlinks would find
   nothing behind it and the test would still pass. The plan requires "a symlink to a directory outside
   the root"; spec §7.5 is the invariant. The file symlink and the `symlinksSeen === 2` count do not cover it.
   Fix: `mkdirSync(outside)` and `writeFileSync(join(outside, 'secret.txt'), ...)` before the symlink; assert no
   `escape/...` path and nothing containing `secret.txt` under `escape`. Then mutate the scanner to follow
   directory symlinks and confirm the test fails.

## Should fix (next task)

   `scan_errors` row. Plan rule 7 says permission errors are recorded. Return an error and push a row.
2. `scanner.ts:87` opens with plain `'r'`. A file swapped for a symlink or FIFO after the listing is followed
   (symlink) or blocks the scan (FIFO). Open with `O_RDONLY | O_NOFOLLOW | O_NONBLOCK`.

   would cover it without a real mount.

   carries on. Let store errors propagate so the scan is marked `failed`.
